The map-tag list (library/tags.json) holds every tag seen in six sample towns, plus every tag on OpenStreetMap's symbol list, with how it would be drawn and a recommendation; n/a means recommended against, with the reason. To add an object: build it in library/<set>/build.mjs, list it in library/index.json, then run node tools/bake_library.mjs. The tests check every listed object has a shape and every shape matches its builder.
